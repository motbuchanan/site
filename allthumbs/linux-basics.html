Part 1 · The big idea

What an operating system even is

Your computer's hardware is just parts: a chip, memory, a screen, storage. Apps are just instructions. Something has to stand in the middle, managing who gets the chip, who gets memory, and how a tap becomes pixels.

That middle manager is the operating system. Windows is one. Linux is another. Same job, different builds.

The heart of Linux is called the kernel: the core program that talks to hardware directly. Everything else, windows and icons and terminals, is stacked on top of it.

Part 2 · The comparison

Linux vs Windows

Same job, very different philosophy. Tap a topic to open it.

Windows
One product, made and owned by Microsoft. You get the version they ship.
Linux
A free, open-source kernel that thousands of people maintain together. Anyone can read the code, change it, or build their own version on top.
Windows
Basically one flavor: Windows 11 Home or Pro. Small menu.
Linux
Because anyone can build on the kernel, there are many complete packaged versions called distributions (distros): Ubuntu, Mint, Debian, Raspberry Pi OS, and hundreds more. Same engine, different body kits.
Windows
A paid license, usually bundled into the price of the computer.
Linux
Free. Download it, install it on anything, run it on a thousand servers, no bill.
Windows
Desktops and laptops, especially at work. If a machine has Excel on it, it is probably Windows.
Linux
Almost everywhere that is not a desk: web servers, Android phones, smart TVs, routers, Raspberry Pi boards driving digital signage, the machines AI assistants run code on.
Windows
Drive letters. Each disk is its own island: C:\, D:\, a USB stick shows up as E:\.
Linux
One single tree that starts at / (called root). Every disk and USB stick gets grafted onto a branch of that same tree. More on this in Part 3.
Windows
Backslashes in paths: C:\Users\You. Capital letters do not matter: Notes.txt and notes.txt are the same file.
Linux
Forward slashes: /home/you. Capital letters DO matter: Notes.txt and notes.txt are two different files. This one bites every beginner once.
Windows
Built around the mouse. The terminal exists (PowerShell) but most people never open it.
Linux
The terminal is the front door. Typing short commands is faster, scriptable, and works on a server on the other side of the planet. It is why developers love it, and it is what Part 4 teaches you.

Part 3 · The filesystem

One tree, everything on it

On Linux, every file on the machine hangs off one tree. The trunk is /, called root. Folders are branches. Files are leaves. That is the whole model.

Tap folders to open them. Tap anything to learn what it is for.

Tap a folder or file above.

The same idea, two spellings

Windows path
C:\Users\You\Documents\notes.txt
Linux path
/home/you/documents/notes.txt

A path is just an address: the turns you take from the trunk to reach one file. Read /home/you/documents/notes.txt as: start at root, into home, into you, into documents, stop at notes.txt. Your home folder /home/you has a nickname: ~ (the squiggle).

Part 5 · The honest verdict

Do you need to learn this?

If you build web apps and work with AI tools: yes to the small stuff, no to the deep end. You do not need to install Linux or become a server admin. You do need the mental model, because it keeps showing up:

GitHub runs on it. AI coding assistants run their code on it. Raspberry Pi signage boards run it. When any tool shows you a path like /home/user/project/index.html, that is Linux talking. Being able to read that fluently is the actual skill.

Worth learning
  • The tree model and how paths work
  • The eight commands below, cold
  • Reading terminal output without flinching
  • Knowing that ~ means your home folder
Safe to skip for now
  • Installing Linux on your own machine
  • Server administration and networking
  • Permissions, users, and sudo depth
  • Memorizing distro differences
