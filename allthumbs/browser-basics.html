The Painter

What a browser actually does with HTML, CSS, and JS.

A browser is a translator and a painter. It receives plain text, builds a structure from it, dresses that structure up, and paints pixels. Then it stays awake, listening for taps. You use one more than any other program you own, and it hides all of this perfectly.

part 6 · the honest verdict

What to keep, what to skip

Keep this

A page is a tree, not a picture. HTML is the recipe for the tree. CSS is find-and-dress. JS edits the tree live, and that is what "interactive" means. View source is always there, on every site, showing the recipe.

Skip for now

Rendering engine internals, layout algorithms, frameworks, build tools. The tree model above is what those are all built on, and it is enough to read real pages and real code.
