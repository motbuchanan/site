the blind spot

You test the path you built

When I finish an app, I open it and use it the way I built it to be used. Tap the big button, play a round, it works, ship it. That check only proves the one path I already knew about.

A real person turns the phone sideways. They tap the same button four times because the first tap felt slow. Their browser is set to block saving, so the app can't keep anything. They have a smaller phone than mine. None of that is in my head while I'm building, so none of it gets tested.

So I built a second tester, the Breaker, whose whole job is to use my apps badly. On Oct 23 it went through five apps on my site. Two of them were broken for real people: one never drew its chessboard when saving was blocked, and one hid four keyboard letters when the phone was turned sideways. Both were already live on my site.

Hand it to someone who doesn't know

The builder knows which button comes next, so their thumb never goes anywhere else. The fix is to hand the app to something that doesn't know, whether that's a robot, a friend, or a kid.

random taps

A monkey finds what you never tried

The Breaker's main trick is dumb on purpose. It taps random spots, over and over, and writes down every tap. When something crashes, the log shows the exact taps that led there.

This tiny game has six buttons, and you can tap them yourself. The way I play it (New, Move, Move, Save) never crashes. Let the monkey loose and see what it finds.

What random taps can't tell you

The monkey finds crashes, dead ends and screens that fall off the edge. It has no idea whether the game's rules are right, or whether it's any fun. A person still has to play it for that.

the second reviewer

Sort what the Breaker found

A raw test run is a pile of maybe-problems. Some are real, and some come from the test machine itself, which has no graphics chip and no speakers. So a second agent, one that never saw the app being built, reads every finding, opens the code to confirm it, and sorts it into four piles.

Break a real person gets stuck or loses something
Fix a real defect, but nobody is stuck
Improve polish or feel
Not a problem checked and cleared

These eight came out of the real Oct 23 sweep of my site. Sort them the way the reviewer did.

Then break it again

A fix doesn't count until the same test runs again and the problem is gone. The new version number on the badge is how I know my phone is running the fixed file and not an old copy.
