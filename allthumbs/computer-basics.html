The Fast Idiot

What a computer actually is: a very fast worker following a very dumb list.

Every device you own is the same machine wearing different cases. A phone, a laptop, a smart TV, a game console: one worker, one desk, one filing cabinet. Learn those three and half of tech support suddenly makes sense.

part 1 · the mental model

Worker, desk, cabinet

Three parts do almost everything. The processor (CPU) is a worker: incredibly fast, tiny attention span. Memory (RAM) is the worker's desk: fast to reach, small, and wiped clean at power off. Storage is the filing cabinet: huge, slower, permanent.

part 2 · what a file actually is

Numbers with a name tag

A file is not mysterious. It is a list of numbers, plus a name. That is the entire secret. What matters is how the numbers get read. Type something:

costume 1 · read as letters
costume 2 · the raw numbers actually stored
costume 3 · read as pixel brightness

This is real: those are the actual character codes of what you typed, and each square's brightness is that same number. One list, three costumes. A text file, an image, a song: all lists of numbers. The .txt or .jpg on the end is just a hint about which costume to use.

part 3 · what a program is

A to-do list for the worker

part 4 · everyday payoffs

Tech support, decoded

"Storage almost full"
Cabinet problem. Delete files, photos, and apps you do not use. Buying a phone with more storage means buying a bigger cabinet.
tap
Everything is laggy with lots of apps open
Desk problem. Every open app keeps papers on the desk. When the desk is full, the worker wastes time shuffling. Closing apps clears desk space.
tap
"Have you tried turning it off and on?"
It works because power off wipes the desk. Whatever tangled mess was sitting in memory is gone, and everything reloads fresh from the cabinet.
tap
Updates need a restart
An update swaps out instruction lists in the cabinet. The safe moment to swap a to-do list is when nobody is reading it, so the machine restarts to let go of everything first.
tap
part 5 · the honest verdict

What to keep, what to skip

Keep this

Worker, desk, cabinet. A file is numbers plus a name tag; the extension is a costume hint. A program is an instruction list, and running it means the worker walking the list. Memory is wiped at power off; storage is not. That model explains most everyday computer behavior.

Skip for now

Transistor physics, binary arithmetic, assembly language, instruction pipelines, cache levels. All real, none needed for the mental model. The toy CPU above is closer to the truth than you might think.
