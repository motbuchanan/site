symptom and cause

"It's broken" is where you start

A bug shows up as a symptom: a blank screen, a button that does nothing, a score that says NaN. The root cause is the one line or the one missing step that makes it happen. Fixing the symptom (hiding the NaN, wrapping more code around the button) makes the bug quieter, and it comes back somewhere else.

Before I ask for any fix now, I work through four questions in order:

1. Can I make it happen again? Same taps, same phone, same result. If I can't repeat it, I can't prove I fixed it.
2. Am I looking at the file I think I am? The version badge answers this. An old copy has fooled me before.
3. Where exactly does it break? Cut the problem in half until one piece is left.
4. Did the fix really work? Run the same taps again and watch the symptom stay gone.

stale or real

The fix didn't work. Or did it?

You uploaded a fix, opened the app, and the bug is still there. There are four very different reasons that can happen, and only one of them means your code is still wrong. Gather evidence before you decide.

your verdict

Why every app has a badge

Early on, a caching problem kept showing me an old copy of an app, and I thought my fixes weren't landing. Now every app shows its version and date, and it's the first thing I look at. One more thing: right after an upload, Pages can take a minute to publish, so give it a moment before you call anything stale.

cut it in half

Find the one bad piece in three tests

This page has eight pieces, and one of them breaks it. Testing them one by one could take up to seven tests. Instead, switch half of them off and test. If the page works, the bad piece is in the half you switched off. If it still breaks, it's in the half that's still on. Keep halving.

How I used this on Nov 13

Firebase sign-in sat silent when a page was opened from Downloads. I had a test page try three steps in order: load the library, sign in, read one page. Step one worked, and step two never answered. That narrowed it to sign-in in one run, without guessing.
